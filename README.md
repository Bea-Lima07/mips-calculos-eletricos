 Cálculos Elétricos em Assembly (MIPS)

Programa desenvolvido em **Assembly MIPS**, com o objetivo de realizar **cálculos elétricos básicos** a partir de valores fornecidos pelo usuário, executado em ambiente local.

---

 Objetivo do Projeto

Este projeto foi criado com fins acadêmicos para praticar:
- Programação em baixo nível
- Manipulação de registradores
- Uso de instruções aritméticas
- Entrada e saída de dados via syscalls

O programa simula um cálculo simples de consumo elétrico.

---

 Funcionamento

O usuário informa os seguintes valores:

- **Tensão (A)**
- **Corrente (B)**
- **Tempo de uso (C)**
- **Fator de eficiência (D)**

A partir desses dados, o programa calcula:

- **Potência (P)** = Tensão × Corrente  
- **Energia Total (E)** = Potência × Tempo  
- **Energia Útil (U)** = Energia Total ÷ Fator de eficiência  

Os valores lidos e os resultados calculados são exibidos no terminal.

---

 Tecnologias Utilizadas

- Assembly MIPS
- Syscalls para entrada e saída
- Ambiente de simulação (ex.: MARS ou SPIM)

---

 Execução

Este projeto é executado **localmente**, utilizando um simulador de Assembly MIPS.
